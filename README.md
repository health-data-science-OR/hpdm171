# 🏥 HPDM171: Python for Health and Life Sciences

Practical notebook materials for the **HPDM171: Python for Health and Life Sciences** module. This course provides an introduction to Python programming with a focus on applications in health and life sciences data analysis.

## 📖 Overview

This repository contains teaching materials, including lecture notebooks, practical exercises, and solutions. Starting from foundational Python concepts, the course progresses through scientific computing with NumPy, data manipulation with pandas, data visualisation with Matplotlib, and object-oriented programming — all in the context of health and life science applications.

## 🎯 What You'll Learn

- Python fundamentals: variables, data types, conditionals, loops, and functions
- Scientific computing with NumPy arrays and vectorised operations
- Statistical analysis and simulation in Python
- Data manipulation and analysis with pandas
- Data visualisation with Matplotlib
- Working with real-world health data sets
- Object-oriented programming concepts and applications

## 🚀 Quick Start

### Prerequisites

- **Python**: 3.12 or higher
- **Jupyter**: JupyterLab or Jupyter Notebook

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/health-data-science-OR/hpdm171.git
   cd hpdm171
   ```

2. **Create the conda environment**
   ```bash
   conda env create -f binder/environment.yml
   conda activate hds_python
   ```

3. **Launch Jupyter**
   ```bash
   jupyter lab
   ```

## 📚 Course Structure

### Week 1: Introduction to Python

**Lecture**: Introduction to the Python Language  
**Practical**: Basic Python  
**Topics**: Variables, data types, basic input/output, expressions

### Week 2: Conditionals and Loops

**Lecture**: Conditionals and Loops  
**Practical**: Conditionals and Loops  
**Topics**: `if`/`elif`/`else` statements, `for` and `while` loops, iteration

### Week 3: Functions and Dictionaries

**Lecture**: More on Functions, Built-in Functions, and Dictionaries  
**Practical**: Functions and Scientific Coding  
**Topics**: Function definition, scope, built-in functions, dictionary data structure

### Week 4: Consolidation

**Lecture**: Consolidation: Loops, Functions, Conditionals, and Data Structures  
**Practical**: Consolidation exercises  
**Topics**: Review and practice of weeks 1–3 material

### Week 5: NumPy — Arrays and Vectors

**Lectures**: Arrays vs lists, Vectors and matrices, Array slicing and indexing, Array algebra  
**Practical**: Working with an `np.ndarray`  
**Topics**: NumPy arrays, vectorised operations, matrix algebra, indexing

### Week 6: NumPy — Statistics and Simulation

**Lectures**: Statistical procedures, Random variables and simulation, Case study: a bootstrap routine  
**Practical**: Statistical procedures in NumPy  
**Topics**: Descriptive statistics, random number generation, NumPy code optimisation.

### Week 7: pandas — DataFrames and Files

**Lectures**: Introduction to pandas, Working with files  
**Practical**: Working with a `pandas.DataFrame`  
**Topics**: Series and DataFrames, reading/writing CSV files, data inspection

### Week 8: Real Data and Matplotlib

**Lectures**: Analysing real data sets, Introduction to Matplotlib  
**Practical**: ED data wrangling  
**Topics**: Real-world health data analysis, data cleaning, plotting and visualisation

### Week 9: Consolidation (NumPy and pandas)

**Lecture**: Weeks 5–8 Consolidation: NumPy and pandas Essentials  
**Practical**: Consolidation practical  
**Topics**: Review and practice of weeks 5–8 material

### Week 10: Object-Oriented Programming

**Lecture**: Introduction to Object Orientated Programming (OOP)  
**Practical**: Basic Object Orientated Methods  
**Topics**: Classes and objects, methods and attributes, text adventure game project

## 🛠️ Key Technologies

## 🎯 Learning Outcomes

After completing this module, you will be able to:

1. Write Python programs using variables, conditionals, loops, and functions
2. Perform numerical computations efficiently using NumPy arrays
3. Conduct statistical analyses and simulations in Python
4. Load, clean, and analyse real-world health data with pandas
5. Create informative visualisations with Matplotlib
6. Design and implement Python classes using object-oriented programming
