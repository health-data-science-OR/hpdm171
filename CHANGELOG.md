## [v0.1.0] - 2026-09-03

🌱 Initial release of HPDM171 teaching materials.

### Added

- **Weeks 1–4: Python fundamentals** — lecture notebooks, practical exercises, and solutions covering variables and data types (week 1), conditionals and loops (week 2), functions and dictionaries (week 3), and a consolidation week (week 4).
- **Weeks 5–6: NumPy** — four-part lecture series (arrays vs lists, vectors and matrices, array slicing and indexing, array algebra) plus practicals (week 5); statistical procedures, random variables and simulation, and a bootstrap case study (week 6).
- **Week 7: pandas** — lectures on pandas fundamentals and file I/O, plus practical exercises working with `DataFrame` objects.
- **Week 8: Real data & Matplotlib** — lectures on analysing real datasets and Matplotlib, with an emergency department data wrangling practical.
- **Week 9: Consolidation (NumPy & pandas)** — review lecture and practical covering weeks 5–8 material.
- **Week 10: Object-Oriented Programming** — OOP lecture, practical exercises, and a text adventure game project (`basic_game.py`, `advanced_game.py`).
- **Environment configuration** — `binder/environment.yml` for conda environment setup.
- **Citation metadata** — `CITATION.cff` for software citation.
- **Documentation** — `README.md`, `example_README.md`, `example_CHANGELOG.md`, and `CHANGELOG.md`.
